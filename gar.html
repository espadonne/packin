About

Gar is a tiling window manager for X11 built entirely in Rust. It provides automatic window tiling, multiple workspace support, and extensive configurability through Lua scripting. Part of the gardesk desktop environment suite.

This package is part of the gardesk desktop environment suite. For the complete experience, consider installing the companion packages: garbar, garbg, garclip, gardm, garfield, garlaunch, garlock, garnotify, garshot, garterm, and gartray.

Automatic Tiling

Windows automatically tile in various layouts (bsp, master-stack, columns)

Lua Configuration

Fully scriptable configuration with Lua for keybindings and rules

Multi-Monitor

Full support for multiple monitors with per-monitor workspaces

IPC Control

Control the WM via garctl for scripting and automation

Getting Started

Add gar to your .xinitrc or display manager session:

# ~/.xinitrc exec gar

Basic Configuration

Configuration lives in ~/.config/gar/config.lua:

-- Example keybindings gar.bind("Mod4-Return", "spawn", "garterm") gar.bind("Mod4-d", "spawn", "garlaunch") gar.bind("Mod4-q", "close") gar.bind("Mod4-1", "workspace", 1) gar.bind("Mod4-2", "workspace", 2) -- Layout settings gar.set("default_layout", "bsp") gar.set("gaps", 8)
