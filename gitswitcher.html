🔄 Gitswitcher - Git Identity Management

Secure Git identity and SSH/GPG key management for seamless account switching

📦 Package Renamed
This package was previously named "gitswitch-c" but has been renamed to "gitswitcher" to avoid confusion with an existing unrelated package called "gitswitch". This is a standalone tool with its own unique functionality.

Gitswitcher is a secure Git identity and SSH/GPG key management tool built in C with security hardening for developers working with multiple Git accounts. It ensures credentials never leak between identities through complete environment isolation, comprehensive health checking, and secure configuration management.

Full Usage Documentation

Usage: gitswitch [OPTIONS] [COMMAND] [ARGS] Complete Git Identity Management Secure git identity switching with comprehensive environment isolation Commands: add Add new account interactively list, ls List all configured accounts remove <account> Remove specified account status Show current account status doctor, health Run comprehensive health check config Show configuration file information <account> Switch to specified account Options: --global, -g Use global git scope --local, -l Use local git scope (default) --dry-run, -n Show what would be done without executing --verbose, -V Enable verbose output --debug, -d Enable debug logging --color, -c Force color output --no-color, -C Disable color output --help, -h Show this help message --version, -v Show version information Examples: gitswitch add # Add new account interactively gitswitch list # List all accounts gitswitch 1 # Switch to account ID 1 gitswitch work # Switch to account matching 'work' gitswitch remove 2 # Remove account ID 2 gitswitch doctor # Run health check Key Features: - Secure TOML configuration management - Interactive account creation with validation - Comprehensive account health checking - Complete SSH key isolation per account - GPG environment separation and management - Configuration validation and security checks - Atomic configuration file operations - Safe file permission handling - Actual git configuration switching - Repository detection and scope management - Security-focused design with hardening
