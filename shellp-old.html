📝 Shellp

Your Friendly Development Note-Taking Companion

🎯 What is Shellp?

Shellp is a CLI tool that encourages better developer note-taking by gently prompting you to document important development activities. It integrates seamlessly with your shell to detect significant commands and helps you build a rich history of your development decisions and thought processes.

🎯 Smart Detection

Automatically detects important development commands (git, npm, docker, make) and prompts for context when it matters.

📝 Rich Management

Organized storage with automatic categorization, tagging, and full-text search capabilities.

🔗 Project Intelligence

Tracks repository changes, links notes to commits, and discovers connections across projects.

🚀 Team Sharing

Export/import note bundles and integrate with Slack, Discord, and custom webhooks.

🚀 Installation

Method 1: Repository Installation (Recommended)
# Add the musicsian repository sudo dnf config-manager --add-repo https://repos.musicsian.com/musicsian.repo # Install shellp sudo dnf install shellp # Set up shell integration sudo /usr/share/shellp/install_hooks.sh
Method 2: Direct RPM Installation
# Install directly from URL sudo dnf install https://repos.musicsian.com/RPMS/shellp-1.0.0-1.el9.x86_64.rpm # Set up shell integration sudo /usr/share/shellp/install_hooks.sh

💻 Quick Start

# Navigate to a project and run development commands cd my-project git status # Shellp will prompt for a note npm install # Another prompt opportunity # View your development story shellp notes # Search through your notes shellp search "database migration" shellp search --tag bugfix shellp search --category git # Manage existing notes shellp manage list shellp manage edit 3 # Project insights shellp links show shellp stats --recent 30d

✨ Key Features

  • Context-Aware Prompting: Understands your project structure and git repository state
  • Automatic Organization: Smart categorization and tagging of development activities
  • Powerful Search: Full-text search with filtering by categories, tags, and dates
  • Cross-Project Linking: Connect related work across different repositories
  • Team Collaboration: Share note bundles and integrate with team tools
  • Performance Optimized: Intelligent caching for fast operations on large note collections
  • Editor Integration: Use your preferred $EDITOR for longer notes
  • External Integrations: Connect with Slack, Discord, and custom webhooks

📋 System Requirements

  • Operating Systems: RHEL 9+, CentOS Stream 9+, Rocky Linux 9+, AlmaLinux 9+, Fedora 35+
  • Architecture: x86_64
  • Dependencies: bash, git (automatically handled by package manager)
  • Shell Support: bash, zsh (with hooks)

🔧 Configuration

Shellp stores configuration in ~/.shellp/config.json and can be customized:

# View current configuration shellp config show # Adjust prompt timeout shellp config set prompts.timeout 60 # Configure editor preference shellp config set editor.preferred "code --wait" # Enable auto-categorization shellp config set rules.auto_categorize true
