🦀 fackr - Terminal Text Editor

Terminal text editor written in Rust - facsimile reimplementation

v1.2.0

fackr is a terminal text editor written in Rust, a reimplementation of facsimile with VSCode-style keybindings. It provides a familiar editing experience for developers who appreciate the power of keyboard shortcuts combined with the efficiency of terminal-based workflows. Built with a rope-based text buffer using the ropey crate for efficient editing.

✨ Key Features

⌨️ VSCode-Style Keybindings

Familiar keyboard shortcuts including Ctrl+C/V/X for clipboard, Ctrl+S to save, and many more.

🦀 Written in Rust

Built with Rust for memory safety and performance. Uses the rope data structure for efficient text operations.

📋 System Clipboard

Full clipboard integration via the arboard crate that works seamlessly across platforms.

🚀 Fast & Lightweight

Optimized release builds with LTO for maximum performance in terminal editing.

🎬 Usage Examples

Basic Usage: # Edit a file fac filename.txt # Create a new file fac newfile.md # Or use the full name fackr mycode.rs Essential Keybindings: Navigation: - Arrow keys: Move cursor - Ctrl+A / Home: Start of line - Ctrl+E / End: End of line - Alt+Left/Right: Word jump - PageUp/PageDown: Page scroll Editing: - Ctrl+C: Copy - Ctrl+X: Cut - Ctrl+V: Paste - Alt+Up/Down: Move line File Operations: - Ctrl+S: Save - Ctrl+Q: Quit

💡 Why fackr?

A terminal editor that doesn't force you to learn new shortcuts: ✓ VSCode keybindings you already know ✓ Written in Rust for safety and speed ✓ Cross-platform clipboard support ✓ Runs in the terminal for SSH sessions ✓ Rope-based text buffer for efficiency ✓ Lightweight and fast startup

🔧 Requirements

System Requirements: - Linux x86_64 (RHEL/CentOS/Rocky/Alma/Fedora 9+) - Terminal with ANSI escape sequence support Dependencies: - glibc - libgcc
