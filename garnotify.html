garnotify

Notification daemon for X11

v0.1.0 gardesk suite New

About

Garnotify is a notification daemon for X11 built in Rust. It implements the freedesktop.org Desktop Notifications Specification, providing a clean and themeable way to display notifications from any application.

This package is part of the gardesk desktop environment suite.

FreeDesktop Compliant

Implements the standard D-Bus notification interface

Action Buttons

Supports notification actions and callbacks

Urgency Levels

Different styling for low, normal, and critical notifications

Notification History

View past notifications via garnotifyctl

Usage

# Start the notification daemon garnotify # Test with notify-send notify-send "Hello" "This is a test notification" # View notification history garnotifyctl history # Clear all notifications garnotifyctl clear # Toggle do-not-disturb garnotifyctl dnd toggle

Autostart with gar

gar.autostart("garnotify")

Configuration

Configuration in ~/.config/garnotify/config.toml:

# Position and size [window] position = "top-right" width = 350 max_visible = 5 gap = 10 margin = 10 # Timing [timing] default_timeout = 5000 critical_timeout = 0 # 0 = never auto-dismiss # Appearance [appearance] font = "Inter 11" background = "#181b24" foreground = "#e2e8f0" border_color = "#a78bfa" border_width = 2 border_radius = 8 # Urgency colors [urgency.critical] background = "#7f1d1d" border_color = "#ef4444"
