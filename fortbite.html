Overview

FORTBITE is a modern high-precision mathematical calculator implemented in Fortran 2008+. It provides comprehensive mathematical functionality with an intuitive interactive interface, perfect for scientific computing, engineering calculations, and mathematical education.

🔢 High Precision

Configurable decimal precision for accurate calculations

📐 Complex Numbers

Full support for complex arithmetic operations

🔢 Matrix Operations

Create, transpose, and manipulate matrices efficiently

📊 Math Functions

Comprehensive library of trigonometric, logarithmic, and statistical functions

💾 Variables

Store and reuse values with intuitive assignment syntax

🛡️ Error Handling

Robust error detection and user-friendly messages

Installation

RPM-based Systems (RHEL, CentOS, Fedora)

# Add the repository
sudo dnf config-manager --add-repo https://repos.musicsian.com/musicsian.repo

# Install FORTBITE
sudo dnf install fortbite

Manual Installation

# Download and install directly
curl -O https://repos.musicsian.com/RPMS/fortbite-1.0.0-1.el9.x86_64.rpm
sudo rpm -ivh fortbite-1.0.0-1.el9.x86_64.rpm

From Source

# Clone and build
git clone https://github.com/espadonne/fortbite.git
cd fortbite
make
sudo make install

Usage Examples

Basic Arithmetic

$ fortbite
fortbite> 2 + 3 * 4
14.000000000000000

fortbite> (2 + 3) * 4  
20.000000000000000

fortbite> 2**10
1024.0000000000000

Mathematical Functions

fortbite> sqrt(16)
4.0000000000000000

fortbite> sin(pi/2)
1.0000000000000000

fortbite> log(exp(1))
1.0000000000000000

fortbite> abs(-42.5)
42.500000000000000

Matrix Operations

fortbite> ones(2,2)
[2x2 matrix]
  1.0000000000000000  1.0000000000000000
  1.0000000000000000  1.0000000000000000

fortbite> eye(3)
[3x3 matrix]
  1.0000000000000000  0.0000000000000000  0.0000000000000000
  0.0000000000000000  1.0000000000000000  0.0000000000000000
  0.0000000000000000  0.0000000000000000  1.0000000000000000

fortbite> matrix := zeros(2,2)
fortbite> transpose(matrix)
[2x2 matrix]
  0.0000000000000000  0.0000000000000000
  0.0000000000000000  0.0000000000000000

Variables and Precision

fortbite> x := 42.123456789
fortbite> x
42.123456789000001

fortbite> x::5
42.123

fortbite> pi::10
3.1415926536
Note: For nested function calls like transpose(ones(2,2)), use intermediate variables for optimal memory performance:
matrix := ones(2,2)
transpose(matrix)

Features

  • Interactive REPL: User-friendly command-line interface
  • High Precision: Configurable decimal precision (e.g., pi::50)
  • Complex Numbers: Full support for complex arithmetic
  • Matrix Operations: Creation, manipulation, and linear algebra
  • Math Functions: Trigonometric, logarithmic, statistical functions
  • Variable Assignment: Store and reuse values with := syntax
  • Error Handling: Comprehensive error detection and reporting
  • Memory Safe: Robust memory management with leak protection

System Requirements

  • OS: RHEL 9+, CentOS 9+, Fedora, or compatible
  • Architecture: x86_64
  • Dependencies: gfortran runtime libraries (automatically installed)
  • Memory: Minimal footprint, typically < 10MB
