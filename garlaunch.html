garlaunch

Application launcher for the gardesk desktop

v0.3.0 gardesk suite

About

Garlaunch is a fast application launcher for X11 built in Rust. Features fuzzy search, desktop entry support, command execution, and a clean, minimal interface that stays out of your way.

This package is part of the gardesk desktop environment suite. Typically bound to Mod4+d for quick access.

Fuzzy Search

Quick fuzzy matching of application names and commands

Desktop Entries

Indexes .desktop files for all installed applications

Command Mode

Prefix with ! to run arbitrary shell commands

Calculator

Prefix with = for quick calculations

Usage

# Launch garlaunch garlaunch # Typical keybinding in gar config gar.bind("Mod4-d", "spawn", "garlaunch")

Search Modes

firefox # Search applications !htop # Run shell command =2+2 # Calculator mode :emoji # Emoji picker (if enabled)

Keyboard Shortcuts

Enter # Launch selected Escape # Close launcher Up/Down # Navigate results Tab # Autocomplete Ctrl+j/k # Navigate (vim-style)

Configuration

Configuration in ~/.config/garlaunch/config.toml:

# Appearance [appearance] width = 600 max_results = 8 font = "Inter 14" show_icons = true # Behavior [behavior] terminal = "garterm -e" enable_calculator = true enable_emoji = false # Colors [colors] background = "#181b24" foreground = "#e2e8f0" selection = "#a78bfa"
