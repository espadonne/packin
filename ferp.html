ferp - GNU grep in Fortran

A GNU grep clone written in modern Fortran

v0.8.7

ferp is a GNU grep clone written in modern Fortran. It supports basic and extended regular expressions, PCRE patterns with lookahead/lookbehind, recursive directory searching, context lines, colorized output, and many other grep-compatible options.

Key Features

BRE/ERE Support

Full support for POSIX Basic and Extended Regular Expressions with proper anchors, quantifiers, and character classes.

PCRE Patterns (-P)

Perl-compatible regex with lookahead, lookbehind, non-capturing groups, and Unicode character properties.

Recursive Search (-r)

Search directories recursively with --include, --exclude, and --exclude-dir filters for precise file targeting.

Context Lines (-A/-B/-C)

Show lines before and after matches with customizable context. Supports -NUM shorthand (e.g., -3 = -C 3).

Usage Examples

Basic Usage: ferp "hello" file.txt # Search for literal string ferp -i "HELLO" file.txt # Case-insensitive search ferp -n "pattern" file.txt # Show line numbers ferp -c "pattern" file.txt # Count matches Regular Expressions: ferp "hel.o" file.txt # BRE: dot matches any char ferp -E "hel+" file.txt # ERE: one or more 'l' ferp -P "foo(?=bar)" file.txt # PCRE: positive lookahead Recursive Search: ferp -r "TODO" src/ # Search directory recursively ferp -r --include="*.f90" "module" . # Only Fortran files Context Lines: ferp -A 2 "error" log.txt # 2 lines after match ferp -B 2 "error" log.txt # 2 lines before match ferp -C 3 "error" log.txt # 3 lines before and after ferp -3 "error" log.txt # Same as -C 3
